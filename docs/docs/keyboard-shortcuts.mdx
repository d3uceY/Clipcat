# Keyboard Shortcuts

Clipcat is built to be fast. The actions you use most are one key combo away, so you rarely need the mouse.

---

## System-wide Shortcuts

These work from **any application** on your system, even when Clipcat is hidden or minimized to the tray.

| Shortcut | Action |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>V</kbd> | Summon Clipcat (Windows / Linux) |
| <kbd>⌘</kbd>+<kbd>Shift</kbd>+<kbd>V</kbd> | Summon Clipcat (macOS) |

---

## In-app Shortcuts

These work when the Clipcat window is in front.

| Shortcut | Action |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>F</kbd> | Focus the search bar. In Mini Clip mode, or on a small screen, it opens or closes the search bar instead. |
| <kbd>Ctrl</kbd>+<kbd>K</kbd> | Open the command palette |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>P</kbd> | Open the command palette (the same thing) |
| <kbd>Alt</kbd>+<kbd>M</kbd> | Turn Mini Clip mode on or off |
| <kbd>Alt</kbd>+<kbd>H</kbd> | Turn Privacy Mode on or off (blurs every clip) |
| <kbd>Alt</kbd>+<kbd>S</kbd> | Turn sound effects on or off |

On macOS the search shortcut is still <kbd>Ctrl</kbd>+<kbd>F</kbd>, not <kbd>⌘</kbd>+<kbd>F</kbd>. The command palette accepts either key, so <kbd>⌘</kbd>+<kbd>K</kbd> and <kbd>⌘</kbd>+<kbd>Shift</kbd>+<kbd>P</kbd> both open it.

---

## Moving Around Without the Mouse

Mini Clip mode and Quick Paste mode work well from the keyboard. The clip you are on is highlighted, and moving past the last clip wraps around to the first.

| Key | Action |
|---|---|
| <kbd>↓</kbd> / <kbd>↑</kbd> | Move to the next or previous clip |
| <kbd>Enter</kbd> | Paste the selected clip into the window you were using |
| <kbd>Esc</kbd> | Close the search bar if it is open, otherwise clear the selection |
| <kbd>Ctrl</kbd>+<kbd>F</kbd> | Open or close the search bar |

## Tips

- **Quick Paste workflow:** press <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>V</kbd> (<kbd>⌘</kbd>+<kbd>Shift</kbd>+<kbd>V</kbd> on Mac) while you are working in another app. Use the arrow keys to pick a clip, press <kbd>Enter</kbd>, and the clip lands in the window you were using.
- **Command palette:** press <kbd>Ctrl</kbd>+<kbd>K</kbd> to reach most features without opening Settings.
- **Search from anywhere:** once Clipcat is open, <kbd>Ctrl</kbd>+<kbd>F</kbd> jumps to the search box. On a small screen, or in Mini Clip mode, it shows or hides the search bar instead.
- **Mini Clip sticks:** <kbd>Alt</kbd>+<kbd>M</kbd> is remembered between sessions, and Mini Clip keeps the window on top of other apps while it is on.
